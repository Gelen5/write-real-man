# Workflow: Choose Topic

For a user-provided topic, or after they select a discovered opportunity:

1. Write one sentence each for the reader, problem and useful result.
2. Confirm the topic is an AI tool/use with ordinary access. If it requires developer setup, reduce technical depth or explain the prerequisite.
3. Decide whether the idea is `trend`, `hybrid` or `evergreen`. Do not label an evergreen item as current heat.
4. Select `scenario-tutorial`, `beginner-guide`, `use-case`, `problem-solution`, `ordinary-person-news` or `practical-opinion`.
5. Read `references/audience-ordinary-people.md` and `references/scenario-first.md`.
6. If no ordinary-person problem or useful result can be named, transform again or drop the idea.

Do not mistake the newest model, biggest launch or highest engagement count for the best topic.
