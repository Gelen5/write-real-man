## 按内容选择，不按固定轮换

| 主导内容 | 优先主题 | 选择理由 |
| --- | --- | --- |
| 单一对象连续叙事、技术评论、克制判断 | 石墨极简风 / graphite-minimal | 正文连续阅读优先，适合本次环卫稿 |
| 已有分节的案例复盘、多项目对照 | 橄榄手记 / olive-journal | 适合编辑式分节与材料组织 |
| 立场鲜明且已有论证结构的行业评论 | 红白色系 / red-white | 以少量颜色标出冲突 |
| 数据报告、密集流程或清单 | 摸鱼绿 / moyu-green | 原文已有结构时使用卡片和表格 |
| 多产品横向评测 | 摸鱼票据风 / moyu-ticket | 同维度对照，不强塞给叙事稿 |
| 低信息密度的随笔 | 留白禅意风 / zen-whitespace | 阅读节奏较松时使用 |

主题文件与标识每次以实际 theme-index 为准。以上是同一产业观察模式的视觉选择，不恢复普通人教程路由。

## 保护已验收文本

用户要求保留真人表达和按内容套模板：视觉服从定稿。保留正文原句、段落顺序、标题、数字、事实限制和来源。不得为了填满组件而补摘要、导读、英文栏目名、作者介绍、互动口号、重复金句或章节。原文无二级标题就不造目录；未提供署名就不造署名区。仅套已有内容需要的容器、字号、留白和少量原词强调。

这项用户定稿保护要求优先于上游默认附加签名、CTA和引言的要求。若标点规范会改变受保护文字，记录改动；不得在不说明的情况下声称 HTML 文本与检测稿完全一致。

## 交付

保存原始 Markdown、纯 section 正文 HTML、复制按钮预览。使用安装 Skill 的绝对路径运行 `scripts/validate_gzh_html.py`，修复 ERROR 与标点 WARNING，再运行 `scripts/wrap_preview.py`。检查渲染文本有无增删、来源链接是否完整，交付主题选择理由与验证结果。排版不包括发布公众号。

## 强制文字一致性检查

依 `acceptance.md` 锁定检测稿。运行 `python scripts/acceptance.py layout article.md clean.html`，文字或有序链接不一致即停止验收。不得增加 END、英文标签、摘要、目录或原稿没有的编号；标题必须保留在可比对产物中。上游 HTML 校验通过不代表文字一致。
