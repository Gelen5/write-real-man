# Third-party notes

This repository is an independent implementation.

Public projects and documentation that influenced the architecture include:

- Tencent EdgeOne / Zhuque official API documentation: external detector response model and label semantics.
- Sophomoresty/zhuque: demonstrated useful CLI-style structured Zhuque output and segment-level inspection.
- qoqu/anti-zhuque: inspired the idea of deterministic preflight diagnostics before external evaluation.
- KKKKhazix/human-writing and similar human-writing skills: reinforced research/material gates and authored Chinese prose principles.
- technical-writing style skills: reinforced preservation of technical literals, code and factual behavior.

No third-party source code is copied into this repository. If code is added later from another project, preserve its license and attribution explicitly.
