# 5分钟变1秒，这辆不扫地的车盯上了环卫考核表

AI 智能落地观察 · 第 17 篇

疆迪力 | 2026.09.22

这辆车不扫地。它沿路收集积尘和图像，数据回到平台以后，麻烦才刚开始：谁接单，谁复核，谁为结果负责。

|  |  |
| :-: | :-: |
| **5分钟 → 1秒** | 单点道路积尘采样时间 |
| **19省42城** | 同一企业无人洗扫机器人的公开应用范围 |
| **10克/平方米以内** | 北京经开区测试路段的浮尘结果 |

9月16日，武汉，一辆小型纯电动车驶出测试区。车顶摄像头转着，车底的采样口贴近路面。它沿着设定路线走了一圈，又自己回到停车位。

这辆车没扫地。

它做的事，是把路有多脏记下来：积尘多少，哪里有漂浮物，问题出在哪一段，位置能不能对上。过去这件事得靠人停车、取样、称重。现在，车不停，数据跟着走。

乍一看，只是给环卫多装了一双眼睛。可这双眼睛会记时间、记位置，还准备把问题直接派给下一辆车。事情走到这里，就碰到了环卫公司每个月都要面对的那张考核表。

## 01 先把“这条路很脏”说清楚

道路保洁有个挺较真的办法，叫“以克论净”。在固定面积里采集灰尘，称出重量，再判断道路是否达标。它比站在路边看一眼客观，但也慢。

据武汉市政府网站转载的长江日报报道，人工单点采样大约需要5分钟，只能挑重点道路抽查。此次下线的无人驾驶环卫综合巡检车把单点采集压到1秒，同时带回积尘、图像和位置信息。[武汉市政府的报道](https://www.wuhan.gov.cn/sy/whyw/202609/t20260918_2849429.shtml)

5分钟和1秒的差别，放在一个点位上不算吓人。放到一座城里，意思就变了。以前只能挑重点道路抽查，现在才有可能沿着整条路反复走，抽查留下的空白也会跟着变小。

我在意的不是快了多少倍，而是抽查变成连续记录以后，原来藏在抽查间隙里的东西，会不会被翻出来。

不过，车采到数据，不等于路已经干净。它只完成了第一步。

## 02 看见垃圾以后，订单发给谁

按公开介绍，车带回的积尘数据会和图像、位置放在一起，形成道路污染画像，锁定责任路段和污染源。巡检结果还可以通过云平台，直接向无人驾驶清扫车、除尘车下发作业订单。

这里有一个容易写过头的地方。报道说的是“可以下发”，新车目前仍在测试验证，计划下一步部署到沈阳。它还不是一套已经在全国稳定运转的无人环卫系统。[新华网的现场报道](http://www.news.cn/energy/20260917/202e7dbd415d4d0d8ffccb2aabb02a66/c.html)

好在，链条后半段并非只停在图纸上。武汉市政府披露，极景的无人洗扫机器人已在19个省、42个城市投入使用。北京经开区今年也做过两个月对比测试：运成街、兴盛街使用智能设备，景园街保留传统人工作业。测试路段作业后每平方米浮尘不足10克，达到北京市二级道路洁净标准。

北京最后留下的方案是“智能机扫+人工精扫”。无人车管大面积、重复的活，人去处理边角、突发情况和机器够不到的地方。加水、充电、排污还得有人管，狭窄路面和不规则障碍也会让算法犯难。[北京经开区公布的测试情况](https://kfqgw.beijing.gov.cn/cxyzkfq/cxcg/202608/t20260821_4831532.html)

所以，这条链目前能看见四段：巡检车发现问题，平台生成任务，无人清扫车去现场，人把机器没收好的尾巴处理掉。

少一段都不行。只买巡检车，后台天天多出一堆没人接的告警；只买清扫车，它照着固定路线来回跑，干净的地方可能又扫一遍，真正脏的路段还在等。

## 03 一辆车，碰到了环卫生意最硬的那张表

今年6月，西安市雁塔区采购了一套智慧环卫车联网考核平台，成交金额29.82万元。采购内容里有车辆运行、现场视频、作业违规分析、巡检监管和质量考核。钱已经有人花了，买方也很明确：城市管理部门。[中国政府采购网公告](https://www.ccgp.gov.cn/cggg/dfgg/cjgg/202606/t20260626_26822541.htm)

环卫合同本来就不是干完活自动拿全款。上海一份2026年度道路环卫保洁合同写得很直接：先服务后付费，根据考核结果支付上一周期服务费。[上海政府采购合同](https://jpg.zfcg.sh.gov.cn/sh-gov-open-doc/1108QZ/cec0f54f-00bb-4a68-8ac3-a7d39c66ac85.pdf)

过去的问题在中间。合同可以按质量付钱，可质量怎么量，仍大量依赖定点抽查、现场照片和人工记录。检查的人不可能每条路都守着，干活的人又清楚检查习惯。两边都累，中间还留着争议。

我的判断是，武汉这辆车真正碰到的，是这块最难啃的地方：把“哪里脏、什么时候发现、何时派单、谁去处理、处理后有没有变干净”留在同一条数据链上。

先别急着说它已经改变了付费模式。公开材料没有说明，武汉项目是否会直接拿巡检数据扣减环卫企业的服务费。数据能不能进入合同，出现误报后谁来复核，企业不认这笔扣款时拿什么申诉，这些问题都还摆在桌面上。

如果再往前推一步，我的设想是，将来环卫项目招标，采购清单里会逐渐多出一类不显眼的系统。它不负责扫地，只管把检测数据、作业订单、复核记录和费用结算接起来。运营公司真被扣了钱，至少能回头查清是哪条路、哪一次作业、哪组数据出了问题。

## 04 车能跑，账未必算得清

数据听起来客观，采集它的机器却没有那么省心。

车底采样口离地多高、车辆抖不抖、气流怎么走，都会影响积尘数据；摄像头脏了，垃圾识别也会打折。新华网的报道提到，研发团队专门调整了减震和传感器布局，还要做联合标定。换一款底盘、换一条坑洼路，之前那套参数未必能原样搬过去。

调度也不是画一条箭头就算接通。一个城区可能同时用着几家公司的清扫车、洒水车和人工班组。巡检平台发出一张工单，谁先接、多久必须到、下雨时要不要暂停、机器进不了小巷怎么办，都得有人定规则。所谓全自动，落到这里还是一堆具体的接口和责任。

更麻烦的是考核。机器说这条路脏，运营公司说刚扫过；识别出一个塑料袋，几秒后被风吹到了隔壁路段；同一辆车既参与作业，又参与验收，数据由谁保管才让双方都服气？这些不是模型再大一点就会自己消失的问题。

造车公司解决不了这里的全部问题。传感器需要反复标定，不同品牌的车辆要接进同一个调度台，人工复核的过程还得留下记录。至于谁能把这些活做成一套标准产品，公开材料里暂时找不到答案。

武汉这辆车下一步要去沈阳验证运营模式。等它真正上路，我最想看的不是一天跑多少公里，而是发现一处积尘以后，那张订单有没有被接走，清扫车多久到，复检结果最后进没进考核表。

一条路扫干净，过去常靠班组长走过去看一眼。以后，他手里也许会多一串时间、位置和重量数据。

那串数据要是进了合同，这辆不扫地的车，才算真的开进了环卫产业链。
