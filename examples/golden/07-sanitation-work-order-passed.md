# 无人车查出路没扫干净，这笔账该算谁的？

9月16日，武汉下线了一辆无人驾驶环卫综合巡检车。它沿路采集积尘，识别垃圾，再把图像和位置传回平台。

报道里有一句话值得多看一眼：巡检结果可以直接变成作业订单，发给无人清扫车、除尘车。

如果这一步能稳定运行，发现路脏了以后，就不用再由一个人看屏幕、记下位置、打电话找车。系统能把任务往下送。但接到任务的车过去扫了一遍，订单就可以关掉了吗？

我觉得还差一次检查。车去过，和路扫干净了，是两件事。

武汉市政府网站转载的长江日报报道说，过去人工单点采样大约要5分钟，这辆车将单点采集压到了1秒。这个数字说的是采样，不能拿来当整套环卫作业的提速幅度。把积尘采回来以后，还要处理数据、判断问题，再安排车辆。[来源：武汉市政府](https://www.wuhan.gov.cn/sy/whyw/202609/t20260918_2849429.shtml)

跟着一张订单往下想，倒容易看清它能做什么。

假设巡检车在某个路口测到积尘超标，传回记录。平台找到负责这段路的清扫车，把位置和任务发过去。清扫车完成作业，上传记录。到这里，后台能确认有人接了活、车也到了现场。

接下来才是我想加上的一环：安排复检，把同一路段作业前后的结果放在一起。如果仍然不达标，订单继续留着，交给现场人员处理。

这是根据已有功能提出的设想。目前公开报道能确认的是检测和派单能力，不能据此认定武汉已经把这套复检流程跑通。新华网写得很清楚，新车还在测试验证阶段，后续计划到沈阳验证运营模式。[来源：新华网](http://www.news.cn/energy/20260917/202e7dbd415d4d0d8ffccb2aabb02a66/c.html)

清扫这一头，有其他地方的实践可以对照。

北京经开区今年做过一轮对比测试，时间从3月11日到5月11日。运成街、兴盛街试用智能设备，景园街作为传统人工作业的对照路段。当地公布的结果是，无人车作业后路面每平方米浮尘不足10克，达到北京市二级道路洁净标准。

这份材料没有把人从流程里删掉。当地继续探索的是“智能机扫+人工精扫”，加水、充电、排污也仍是需要解决的环节。路面窄了，旁边有不规则障碍物，机器在边缘位置的作业精度还要改。[来源：北京经开区](https://kfqgw.beijing.gov.cn/cxyzkfq/cxcg/202608/t20260821_4831532.html)

所以，前面那张假想订单如果发到一条机器进不去的小巷，就得转给人工。系统至少要记下转给了谁，不能因为无人车到不了，就把这条任务搁在那里。

武汉负责检测，北京的测试让我们看到清扫和人工补位的情况。把两处材料放在一起看，能想到一种更完整的作业安排。但它们是不同地方的项目，还不能当成同一套系统的成绩单。

再往下查，环卫考核本身已经有采购需求。

中国政府采购网6月26日公布，西安市雁塔区一个智慧环卫车联网考核平台项目成交，金额29.82万元。清单里包括车辆运行管理、现场视频、巡检监管、质量考核，还有部署、运维和培训。这能说明，有部门愿意为管理和考核系统付钱；至于用了以后改善多少，成交公告没有给出答案。[来源：中国政府采购网](https://www.ccgp.gov.cn/cggg/dfgg/cjgg/202606/t20260626_26822541.htm)

我的设想就落在这几件东西中间：把巡检记录、清扫订单和复检结果接到考核系统里。

比如，一个月结束，某条路有几次没有达标。负责项目的人点开记录，能看到当时的位置、图像、检测结果，也能看到清扫车何时到达、后来有没有安排人工补扫。有异议，就对着同一份记录查。

这类系统是否值得买，要看它能不能减少现有工作中的麻烦。一个城区如果用了不同厂家的设备，数据格式不一样，调度平台又各管各的，先把工单接通就需要人做。后面还有设备标定、记录保存、异常复核和日常维护。对于想做AI行业应用的人，这些是可以继续调查的业务需求。买方、预算和验收条件，得逐项问清楚。

我不太愿意现在就把它写成一个成熟市场。29.82万元是一份具体采购的金额，推不出别的城市也会买，更推不出做这门生意的利润。

还有一个问题绕不开：检测结果开始影响考核以后，谁来确认检测本身没出错？

新华网的现场报道提到，积尘采样对安装位置、气流和车辆抖动都很敏感，研发团队为此调整了减震和传感器布局，并做联合标定。采样快到1秒，也仍然要经过这些工作。

不妨设想一次争议。环卫公司刚完成清扫，巡检结果却显示超标。现场人员提出，检测时有施工车辆经过，带来了新的积尘。此时如果平台只留一个分数，没有检测时间、现场图像和作业记录，复核的人仍然得重新去问。

这个例子是假设的，但系统设计时需要考虑这样的情况。发现问题、安排处理以后，还得允许相关人员补充证据，不能把机器给出的第一次结果直接当成最后结论。

目前，公开材料没有说明武汉这辆巡检车的数据是否会直接用于合同扣款。它后续到沈阳验证运营模式时，我更想看到一张完整工单：问题几点发现，发给了哪辆车，谁确认完成，复检留下了什么记录。

要是路还没扫干净，这张单就先别关。
