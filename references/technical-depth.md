# Technical depth

Select the lowest level that lets the reader act.

| Level | Use | Include |
| --- | --- | --- |
| 0 | everyday user | no implementation detail; show the task and result |
| 1 | default | explain visible terms and one important limitation |
| 2 | interested user | add practical configuration or feature comparisons when needed |
| 3 | technical reader | APIs, SDKs, architecture, benchmarks; only when explicitly requested |

If an important current fact requires technical detail, explain its everyday consequence first and put the terminology in a short note. Do not use jargon density as a proxy for expertise.
