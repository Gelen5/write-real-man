# Scenario-first article design

Design the task before choosing the outline.

1. **Person:** Who has this problem in an ordinary day?
2. **Friction:** What exact thing is unfinished, confusing, repetitive or easy to forget?
3. **Starting material:** What note, message, photo, file, list or draft can the person actually provide?
4. **Small request:** Write a prompt in the person's own words, with only the context that changes the result.
5. **First output:** Show a plausible result, including a realistic omission or overstatement when useful. Label invented examples as exercises.
6. **Correction:** Quote the error and supply the actual fact. Avoid vague feedback such as “make it better.”
7. **Useful result:** Save, copy, send or use the checked output. Tell the reader what to verify before relying on it.
8. **Next use:** Add one realistic variation only if it helps the same task.

Keep one task in view. Do not turn a small tutorial into a product tour. If no visible starting material or checkable result exists, choose another scenario.
