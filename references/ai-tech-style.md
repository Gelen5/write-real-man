# AI-tech writing style

## Default voice

- Chinese, direct, concrete
- knowledgeable without pretending omniscience
- capable of saying “我不知道 / 目前资料没有说明”
- explains technical detail through consequence and example
- opinionated only where evidence supports a judgment

## Strong openings

Prefer one of:
- a concrete surprising result
- a failure / friction point
- a direct claim with evidence immediately following
- a user problem
- a change that invalidates an old assumption

Avoid generic openings such as:
- “随着人工智能快速发展”
- “在数字化浪潮下”
- “众所周知”
- “不可否认”

## Paragraph function

Each paragraph should primarily do one job:
- introduce a fact
- show an example
- explain a mechanism
- compare alternatives
- expose a limitation
- advance the author’s judgment
- give the next action

If two adjacent paragraphs do the same job, merge or cut one.

## Technical explanation

When introducing a concept:
1. name it correctly
2. explain what changes for the reader
3. show a concrete example if needed
4. stop when the reader can act

Do not turn every term into a textbook definition.

## Conclusions

Do not recap the whole article mechanically.
Prefer:
- a final decision rule
- the main unresolved question
- who should act now and who should wait
- a narrower, sharper version of the thesis
